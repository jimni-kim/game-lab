# 웹 실측 1차 기록: 분리한 하네스의 기준선

작성: 2026-11-13. 커밋 `0f89c41`. 사용자 승인 범위: `ovolve_2048` 1판(모델 없음), `march2048_4x4` 1판(모델 사용).

**이 실측이 재는 것:** 분리한 하네스가 실사이트에서 끝까지 도는지와, 지금 방식(프로필과 손으로 쓴 reader)의 기준선.
생성 어댑터는 아직 없다(실험 계획 단계 4). 두 사이트 모두 ARMY 쪽에서 이미 되던 곳이라 일반화의 증거가 아니다.

## 실행

```sh
python -m gamelab.eval web --profile ovolve_2048 --objective reach_value --target 2048 --compute 500 --max-seconds 3000 --vision-model '' --out out/web/ovolve
python -m gamelab.eval web --site march2048_4x4 --objective reach_value --target 2048 --compute 500 --max-seconds 3000 --vision-model gpt-6.1-sol --out out/web/march4
```

풀이기는 2048 전용 expectimax, 예산 500. 브라우저는 Playwright Chromium(headless), 1280×1000.

## 결과

|---|---|---|
| 판독 | 등록 프로필, 페이지 DOM | 프로필 없음 → 모델의 한 번 보기로 세션 프로필, 화면 픽셀 |
| 결과 | `goal_reached` (`won`, 2048) | `goal_reached` (`reach_value`, 2048) |
| 보낸 수 / 확인된 수 | 1,117 / 1,116 | 989 / 989 |
| 효과 없음·불일치 | 0 | 0 |
| 오독 (정답키와 대조한 수) | 0 / 1,117 | 0 / 989 |
| 재전송 | 0 | 0 |
| 시간 | 830초 | 648초 |
| 한 수 시간 (평균 / p95) | 0.74초 / 0.77초 | 0.65초 / 0.68초 |
| 캡처 수 (수당) | 1,139 (1.02) | 1,004 (1.02) |
| 모델 질문 / 토큰 | 0 | 1 / 입력 3,061, 출력 155 |
| 마지막 점수 | 22,536 | 사이트 정답키에 점수 없음 |

- `ovolve_2048`의 확인되지 않은 1수는 마지막 수다. 2048을 만든 수 뒤에 승리 메시지가 판을 덮어 그 수의 결과 판을 읽지 못했고(`effect: unknown`), 페이지의 승리 표시로 끝을 판정했다.
- `march2048_4x4`의 모델 답 한 번으로 4×4 판과 칸 값이 확인됐고, 시험 수 3수가 규칙대로 움직였다. 플레이 중 새 타일 값의 색은 규칙이 알려 주는 값으로 배웠다(모델 추가 질문 없음).
- 한 수 시간은 ARMY 쪽 기록(1.1~1.2초)보다 짧다. 승인, 입력 직전 픽셀 재검사, 영수증 조회가 빠졌기 때문이라 같은 조건의 비교가 아니다.

## 실측 중 고친 것

- Azure 모델이 `max_tokens`를 400으로 거부해 `max_completion_tokens`로 바꿨다(`0f89c41`).
- `.env`의 모델 이름 `gpt-6.1-terra`는 프록시 목록에 없어 400이 난다. 이번에는 `--vision-model gpt-6.1-sol`로 지정했다.

## 하지 않은 것

- 판 수가 각 1판이다. 승률이나 분산은 말할 수 없다.
- `--perturb`, `--scale`, 지뢰찾기·블록 사이트, 실패하던 사이트(`doge2048` 등), Android.
